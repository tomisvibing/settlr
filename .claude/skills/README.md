# Claude Code skills

The design skills in this folder come from Jakub Krehel's
[jakubkrehel/skills](https://github.com/jakubkrehel/skills)
(the Interfaces collection), copied unchanged at commit
`267330e1adfc66a718fb65fa6918c1f06d0a689e`. They're MIT licensed; the licence
is in [LICENSE-interfaces.txt](LICENSE-interfaces.txt) and must stay with them.

Claude Code loads them automatically in this repo. Some run on their own when
they're relevant (the `better-*` skills); others only when asked by name:
`/interface-review`, `/explain-interface`, `/break` and `/variant`.

To update them, copy the `skills/` folder from a newer commit of that repo
over these and update the commit above.
